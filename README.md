# Halcyon Drift — captive scroll POC

A single-file proof of concept: a captive (sticky) scroll sequence of abstract white bubbles on a neon red background, styled after Designers Republic-era graphic design.

**Run it:** open `index.html` in a browser. No build step.

**Tweak it:** colours are CSS variables at the top of `<style>`; bubble count / seed / smoothing are at the top of `<script>`; captions are the `.panel` blocks.

Fan-made style exercise. Not affiliated with any studio.
